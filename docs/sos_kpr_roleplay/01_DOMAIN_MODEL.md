# Domain Model Rumah Subsidi

## Tujuan Penjualan

Tujuan sales bukan sekadar mendapatkan booking fee.

Tujuan sales adalah membantu prospek yang sesuai untuk bergerak secara aman dan realistis menuju:

`Lead → Inquiry → Survey → Booking → Pemberkasan → Proses Bank → SP3K → Akad → Serah Terima → Referral`

Booking dari prospek yang tidak layak, tidak memahami proses, atau menerima janji palsu tidak boleh dianggap sebagai keberhasilan.

## Status Customer Journey

| Status | Makna | Target Interaksi |
|---|---|---|
| Awareness | Baru mengenal proyek | Bangun ketertarikan |
| Lead | Data kontak tersedia | Memulai komunikasi |
| Inquiry | Aktif bertanya | Menggali kebutuhan |
| Qualified | Layak secara awal | Arahkan ke survey / cek dokumen |
| Survey Scheduled | Jadwal kunjungan dibuat | Pastikan hadir |
| Surveyed | Sudah melihat proyek | Klarifikasi kecocokan |
| Booking Intent | Menunjukkan niat booking | Pastikan pemahaman |
| Booked | Booking selesai | Mulai pemberkasan |
| Document Collection | Dokumen dikumpulkan | Lengkapi kekurangan |
| Bank Submission | Data diajukan | Kelola ekspektasi |
| SP3K | Persetujuan kredit terbit | Siapkan akad |
| Akad Scheduled | Jadwal akad tersedia | Pastikan kesiapan |
| Akad Completed | Akad selesai | After-sales |
| Handover | Unit diserahterimakan | Kepuasan |
| Referral | Memberi rujukan | Maintain relationship |

## Klasifikasi Prospek

### Hot Prospect

- kebutuhan jelas;
- urgensi tinggi;
- kelayakan awal memadai;
- pengambil keputusan terlibat;
- bersedia melakukan next step.

### Warm Prospect

- tertarik tetapi belum siap;
- perlu diskusi keluarga;
- dokumen belum lengkap;
- masih membandingkan;
- kemampuan awal belum pasti.

### Cold Prospect

- hanya mencari informasi;
- tidak memiliki kebutuhan dekat;
- tidak bersedia membuka informasi dasar;
- belum memenuhi syarat utama;
- tidak memiliki rencana tindakan.

## Prinsip Etika

AI harus menilai negatif bila sales:

- menyarankan pemalsuan dokumen;
- menyembunyikan kewajiban kredit;
- menjanjikan pasti lolos;
- memberi informasi regulasi tanpa dasar;
- memaksa booking saat prospek belum memahami;
- merendahkan pekerjaan atau kondisi finansial prospek;
- menekan prospek secara tidak proporsional.
